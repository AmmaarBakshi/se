# KRISHNA STQA - Practical 6: Web Element Interaction and Synchronization Handling

## Aim
Textbox, radio button, checkbox, dropdown, alert aur frame ko Selenium WebDriver se automate karna, aur implicit/explicit waits se synchronization handle karna.

## Requirements
- JDK 17, Eclipse, Selenium Java 4.49.0 (Practical 5 jaisa setup)
- Google Chrome
- Internet

## Folder Contents
- `selenium-webelement-practical6/` : Maven project (com.stqa:selenium-webelement-practical6) with `WebElementInteractionTest`
- `Screenshots/` : apni run ke screenshots yahan save karo (journal ke liye)

## Steps to Run
1. `selenium-webelement-practical6` ko Eclipse me import karo, JRE = JDK 17.
2. `WebElementInteractionTest.java` -> Run As -> Java Application.
3. Console me 7 lines (Textbox, Radio, Checkbox, Dropdown, Alert, Iframe, ExpWait) PASS dikhni chahiye; screenshot lo.

## Result
All 7 element interactions (textbox, radio, checkbox, dropdown, alert, iframe, explicit wait) executed using Selenium WebDriver with implicit and explicit waits.
