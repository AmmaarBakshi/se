# KRISHNA STQA - Practical 10: List and Combo Box Item Verification

## Aim
Web page par dropdown/list identify karna, total items count karna, default selected value validate karna aur selection testing (text, index, value) karna.

## Requirements
- JDK 17
- Eclipse IDE
- Selenium Java 4.49.0
- Google Chrome, Internet

## Folder Contents
- `selenium-dropdown-practical10/` : Maven project com.stqa:selenium-dropdown-practical10 with `DropdownVerificationTest`
- `Screenshots/` : apni run ke screenshots yahan save karo (journal ke liye)

## Steps to Run
1. `selenium-dropdown-practical10` ko Eclipse me import karo, JRE = JDK 17.
2. `DropdownVerificationTest.java` -> Run As -> Java Application.
3. Console output ka screenshot lo.

## Result
The program identified the dropdown, counted its 3 items, validated the default selection ("Please select an option") and tested selection by visible text, index and value. All verifications passed.
