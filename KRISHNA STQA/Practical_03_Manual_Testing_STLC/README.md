# KRISHNA STQA - Practical 3: Manual Test Case Design and Execution

## Aim
Web application ke liye Test Plan, Test Scenarios, Test Cases banana, manually execute karna, aur STLC ke hisaab se Test Execution Report aur Defect Report banana.

## Requirements
- Microsoft Excel / Google Sheets / Notepad
- Google Chrome
- SauceDemo: https://www.saucedemo.com/ (standard_user / secret_sauce)

## Folder Contents
- `1_TestPlan.csv` : Test Plan
- `2_TestScenarios.csv` : 10 scenarios (TS01-TS10)
- `3_TestCases.csv` : 10 test cases (TC01-TC10), last 3 columns execution ke baad fill karne ke liye khali
- `4_TestExecutionReport.csv` : Execution results + summary (10/10 pass)
- `5_DefectReport.csv` : Defect report (koi defect nahi mila)
- `Screenshots/` : apni run ke screenshots yahan save karo (journal ke liye)

## Steps to Run
1. Sab CSV files Excel me kholo.
2. Chrome me SauceDemo kholo aur 3_TestCases.csv ke steps ek-ek karke manually run karo.
3. Actual result observe karke 3_TestCases.csv aur 4_TestExecutionReport.csv me bharo.
4. Excel me sab files open karke screenshots lo (Screenshots/ folder).
5. Test Plan me `Roll Number` aur `Date` apna daal do.

## Result
Manual testing of SauceDemo completed. 10 test cases executed, 10 passed, 0 failed (100% pass). No defects were found.
