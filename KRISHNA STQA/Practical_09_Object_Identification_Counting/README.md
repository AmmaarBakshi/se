# KRISHNA STQA - Practical 9: Object Identification and Counting on Web Page

## Aim
Selenium WebDriver se web page par links, images, buttons, input elements aur headings ko identify karke category-wise count dikhana.

## Requirements
- JDK 17
- Eclipse IDE
- Selenium Java 4.49.0
- Google Chrome, Internet

## Folder Contents
- `selenium-objectcount-practical9/` : Maven project com.stqa:selenium-objectcount-practical9 with `ObjectCountTest` (site: the-internet.herokuapp.com)
- `Screenshots/` : apni run ke screenshots yahan save karo (journal ke liye)

## Steps to Run
1. `selenium-objectcount-practical9` ko Eclipse me import karo, JRE = JDK 17.
2. `ObjectCountTest.java` -> Run As -> Java Application.
3. Console me categorized counts ka screenshot lo.

## Result
The Selenium WebDriver program successfully identified and counted the objects present on the web page. The categorized counts for links, images, buttons, input fields, and headings were displayed in the console using findElements() and By.tagName().
